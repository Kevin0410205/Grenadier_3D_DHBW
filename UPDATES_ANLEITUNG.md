# Updates – kurz und einfach

## Für dich als Entwickler
1. Lokalen Ordner **Grenadier_3D_DHBW** öffnen.
2. Geänderte Dateien ersetzen oder ergänzen.
3. **GitHub Desktop** öffnen.
4. Commit-Nachricht eingeben.
5. **Commit to main** klicken.
6. **Push origin** klicken.
7. Auf GitHub unter **Actions** warten, bis der Lauf grün ist.

Danach ist die neue Version online.

## Für Nutzer / Studenten
- App bleibt installiert.
- App öffnen.
- Bei Bedarf **Offline & Updates → Updates prüfen** wählen.
- Wenn ein Update gefunden wird: **Aktualisieren**.

Eine Neuinstallation ist nicht nötig.

## Gleichzeitig viele Nutzer
Mehrere Personen können die App gleichzeitig ohne Probleme öffnen. GitHub Pages liefert nur statische Dateien aus; es gibt keine gemeinsame Sitzung oder Datenbank, die andere blockiert.
