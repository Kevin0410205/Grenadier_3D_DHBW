# GitHub Pages V6 – Verbesserungen

- GitHub-Pages-Updateprüfung direkt im App-Status.
- Schaltfläche `Offline vollständig speichern` statt nur Intro-Download.
- Fortschrittsanzeige beim Speichern der Intro-Medien.
- Dauerhafte Speicherung wird beim manuellen Offline-Download nochmals aus einer Nutzeraktion heraus angefordert.
- Öffentliche `install.html` für Kollegen mit plattformspezifischer Installationshilfe und Link-Teilen.
- `install.html` und `404.html` werden in die App-Shell aufgenommen und sind offline verfügbar.
- Navigation kann bei einem beschädigten aktuellen Cache auf die vorherige App-Shell zurückfallen.
- GitHub-Actions-Workflow prüft Build-ID-Platzhalter, Pflichtdateien und sehr große Einzeldateien vor dem Deployment.
- README, Ersteinrichtung, Nutzerinstallation und Update-Anleitung ergänzt.
- V40-3D-Inhalt und bestehende Szenenlogik unverändert erhalten.
