App installieren

Die App wird direkt von GitHub Pages installiert. Eine ZIP-Datei müssen Nutzer nicht herunterladen.

App-Adresse

App öffnen

iPhone / iPad

  1. Diese Seite in Safari öffnen.
  2. Auf Teilen tippen.
  3. Zum Home-Bildschirm wählen.
  4. Mit Hinzufügen bestätigen.

Android

  1. Die Seite in Chrome oder einem PWA-fähigen Browser öffnen.
  2. Browser-Menü öffnen.
  3. App installieren bzw. Zum Startbildschirm hinzufügen wählen.
  4. Installation bestätigen.

Windows / Laptop

  1. Die Seite in Edge oder Chrome öffnen.
  2. Das Installationssymbol in der Adressleiste oder das Browser-Menü öffnen.
  3. App installieren wählen.

Offline vollständig vorbereiten

  1. App einmal mit Internet öffnen.
  2. Unten rechts App-Status öffnen.
  3. Offline vollständig speichern wählen.
  4. Warten, bis Offline vollständig verfügbar angezeigt wird.
  5. Danach kann die App ohne Internet gestartet werden. Browser können Offline-Daten bei starkem Speichermangel trotzdem entfernen.

Updates

Eine Neuinstallation ist nicht nötig. Sobald eine neue Version veröffentlicht wurde, prüft die App bei bestehender Internetverbindung automatisch auf Updates. Alternativ: App-Status → Update prüfen. Danach Aktualisieren wählen.

Tipp: Den GitHub-Pages-Link an Kollegen schicken. Jeder installiert dieselbe veröffentlichte Version direkt auf seinem Gerät.
